# Практическая работа 1

HTTP-сервис на Go с использованием стандартного пакета `net/http`. Возвращает текстовое приветствие, данные пользователя с UUID и состояние сервера. Данные не сохраняются.

## Требования

- Go 1.27.1 или новее, согласно `go.mod`.
- Git для клонирования репозитория.

Команды ниже предназначены для PowerShell и выполняются из папки `practice-01`, содержащей `go.mod`.

## Структура проекта

```text
practice-01/
├── cmd/
│   └── server/
│       └── main.go
├── go.mod
├── go.sum
└── README.md
```

`cmd/server/main.go` содержит точку входа, настройки сервера и обработчики запросов. Внешняя зависимость `github.com/google/uuid` версии `v1.6.0` используется для генерации UUID.

## Запуск

```powershell
go mod download
go run ./cmd/server
```

По умолчанию сервер доступен по адресу `http://localhost:8080`. Для остановки нажмите `Ctrl+C` в терминале сервера.

## Настройка порта

Переменная окружения `APP_PORT` задаёт порт при запуске. Если она отсутствует или пуста, используется `8080`.

```powershell
$env:APP_PORT = "8081"
go run ./cmd/server
```

Сервер будет доступен по адресу `http://localhost:8081`. Переменная задаётся в текущем сеансе PowerShell. Для возврата к порту по умолчанию остановите сервер, удалите переменную в этом же терминале и запустите программу заново:

```powershell
Remove-Item Env:APP_PORT
go run ./cmd/server
```

## Проверка маршрутов

Выполняйте запросы во втором терминале при работающем сервере. В примерах используется порт `8080`; при изменении `APP_PORT` подставьте выбранный порт. Параметр `-i` выводит заголовки вместе с телом ответа.

### Приветствие

```powershell
curl.exe -i http://localhost:8080/hello
```

Ожидается статус `200 OK`, тип `text/plain; charset=utf-8` и тело:

```text
Hello, world!
```

### Пользователь

```powershell
curl.exe -i http://localhost:8080/user
```

Ожидается статус `200 OK` и тип `application/json`. Пример тела ответа:

```json
{"id":"03d03dc9-db2c-4253-82db-1af45d63a7bc","name":"Vanek"}
```

UUID генерируется заново при каждом запросе. Имя задано в коде.

### Состояние сервера

```powershell
curl.exe -i http://localhost:8080/health
```

Ожидается статус `200 OK` и тип `application/json`. Пример тела ответа:

```json
{"status":"ok","time":"2026-10-06T08:30:00Z"}
```

Поле `time` содержит текущее время в UTC в формате RFC3339. Маршрут подтверждает, что сервер отвечает; проверки внешних систем не выполняются.

## Сборка

Остановите ранее запущенный сервер перед запуском нового экземпляра на том же порту.

```powershell
go build -o helloapi.exe ./cmd/server
.\helloapi.exe
```

Исполняемый файл создаётся в корне проекта. Он также читает `APP_PORT` при запуске. После изменения исходного кода для обновления `.exe` требуется повторная сборка.

## Форматирование и проверка кода

```powershell
go fmt ./...
go vet ./...
```

`go fmt` форматирует код, а `go vet` выполняет статический анализ. Проверку HTTP-ответов выполняйте отдельно по примерам выше.
